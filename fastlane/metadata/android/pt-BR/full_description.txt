<p>SysctlGUI é um aplicativo Android projetado para usuários avançados, desenvolvedores e entusiastas que desejam ajustar o desempenho de seus dispositivos editando diretamente os parâmetros do kernel. Ele fornece uma interface de usuário para o utilitário de linha de comando <code>sysctl</code>, tornando os ajustes avançados do kernel acessíveis.</p><p><b>Características:</b></p><ul> <li>Navegue facilmente pelo sistema de arquivos ou pesquise em uma lista abrangente para encontrar parâmetros do kernel, com documentação no aplicativo para ajudar você a entender seu impacto. </li> <li>Reaplique automaticamente as configurações escolhidas em cada inicialização.</li> <li>Salve e carregue conjuntos de parâmetros a partir de arquivos de configuração, facilitando a alternância entre diferentes perfis de desempenho ou o compartilhamento de sua configuração. </li> <li>Marque os parâmetros usados com frequência para acesso rápido e fácil.</li> <li>Automatize a aplicação de parâmetros do kernel em resposta a eventos específicos usando o <a href="https://tasker.joaoapps.com/">Tasker</a>.</li></ul>
